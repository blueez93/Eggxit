# Install Eggxit · Installer Eggxit

[Home](../README.md) · [Accueil](README_FR.md) · [Français](#français)

## English

Use **Minecraft Java Edition 1.21.1**, **NeoForge 21.1.265**, **Java 21**, **GeckoLib 4.8 for NeoForge 1.21.1** and **Eggxit 1.0.0**. These are the versions used to validate First Hatch.

### Manual install

1. Install NeoForge and select its Minecraft 1.21.1 profile in the launcher.
2. Open that profile’s game folder. Put the Eggxit release JAR and the GeckoLib JAR in its `mods` folder.
3. Start the NeoForge profile and check that the mod list shows Eggxit 1.0.0.

[NeoForge installation guide](https://docs.neoforged.net/user/docs/) · [GeckoLib 4.8 for NeoForge](https://www.curseforge.com/minecraft/mc-mods/geckolib/files/7009924)

### CurseForge app

When Eggxit is listed on CurseForge, open its official project page and select First Hatch for a Minecraft 1.21.1 NeoForge profile. Check the installed mods for the NeoForge build of GeckoLib 4.8 before starting. [Download status](../README.md#download)

### Server and troubleshooting

Install the matching Eggxit and GeckoLib JARs in `mods` on the NeoForge server and on every client. Back up an existing world before replacing its mod files. [NeoForge server guide](https://docs.neoforged.net/user/docs/server/)

- If the game reports an incompatible loader or game version, check the active profile for NeoForge and Minecraft 1.21.1.
- If GeckoLib is missing or incompatible, check that its installed file is the 4.8 build for NeoForge 1.21.1.
- If a duplicate mod is detected, keep one Eggxit JAR in that profile’s `mods` folder.
- If the launcher reports an incompatible Java runtime, point the profile at Java 21.

## Français

Utilisez **Minecraft Java Edition 1.21.1**, **NeoForge 21.1.265**, **Java 21**, **GeckoLib 4.8 pour NeoForge 1.21.1** et **Eggxit 1.0.0**. First Hatch a été validé avec ces versions.

### Installation manuelle

1. Installez NeoForge et sélectionnez son profil Minecraft 1.21.1 dans le lanceur.
2. Ouvrez le dossier de jeu de ce profil. Placez le JAR Eggxit et le JAR GeckoLib dans son dossier `mods`.
3. Lancez le profil NeoForge et vérifiez qu’Eggxit 1.0.0 figure dans la liste des mods.

[Guide NeoForge](https://docs.neoforged.net/user/docs/) · [GeckoLib 4.8 pour NeoForge](https://www.curseforge.com/minecraft/mc-mods/geckolib/files/7009924)

### Application CurseForge

Lorsque le projet sera disponible, ouvrez sa page officielle et sélectionnez First Hatch pour un profil Minecraft 1.21.1 sous NeoForge. Vérifiez que GeckoLib 4.8 pour NeoForge figure dans la liste des mods avant de lancer le jeu. [État du téléchargement](README_FR.md#téléchargement)

### Serveur et dépannage

Placez les mêmes JAR Eggxit et GeckoLib dans `mods` sur le serveur NeoForge et chez chaque joueur. Sauvegardez votre monde avant de mettre à jour ses mods. [Guide du serveur NeoForge](https://docs.neoforged.net/user/docs/server/)

- Si le jeu signale un problème de version ou de modloader, vérifiez que le profil actif utilise bien Minecraft 1.21.1 et NeoForge.
- Si GeckoLib est absent ou incompatible, vérifiez que le fichier installé correspond à la version 4.8 pour NeoForge 1.21.1.
- Si Eggxit apparaît en double, gardez un seul JAR Eggxit dans le dossier `mods` du profil.
- Si le lanceur signale une version de Java incompatible, sélectionnez Java 21 pour ce profil.
